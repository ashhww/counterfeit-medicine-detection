# Counterfeit Medicine Detection — Indian Drug Market

Final-year capstone project: a multimodal system for detecting counterfeit and substandard
medicines using packaging image analysis, QR/barcode verification, and (optionally) low-cost
spectral readings — with explainable output for field inspectors.

## Folder structure
